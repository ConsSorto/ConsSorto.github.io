# Clase 8: Evolución a Vertical Slicing y Simetría con el Frontend

## Explicación
Romper las capas horizontales clásicas para organizar el código por Features o Módulos (Ej: Feature "Hábitos", Feature "Recompensas"). Explicar cómo el Frontend en React utilizará exactamente la misma estructura mental de carpetas (`src/features/habitos/api`, `src/features/habitos/components`) para lograr una arquitectura coherente y escalable de punta a punta.
