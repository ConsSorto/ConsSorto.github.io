# 📘 UNIDAD 2: Ecosistema Frontend (React) e Integración Continua.

## Introducción
Introducción al Desarrollo Frontend Moderno. Configuración del entorno con Vite, estructura de un proyecto React y comprensión del Virtual DOM.

Configuración del entorno con Vite, estructura de un proyecto React y comprensión del Virtual DOM.

**[11. Componentes Funcionales y JSX](./11.md)**
Creación de interfaces declarativas. Entendiendo la anatomía de un componente principal en React y la inyección de propiedades (Props).

Conexión de los formularios de React con los DTOs de entrada y salida del servidor (Verbos POST y DELETE para los hábitos) validando la comunicación asíncrona.
