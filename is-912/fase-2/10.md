# ⚛️ Clase 10: Introducción al Desarrollo Frontend Moderno, Vite y Virtual DOM

## 📖 Teoría: El Cliente Inteligente y la Evolución del Renderizado

En el análisis de sistemas web tradicionales (como vimos en años anteriores con PHP), el servidor construía el HTML completo y lo enviaba al navegador. Hoy, en arquitecturas modernas API-First, construimos Single Page Applications (SPAs). El servidor solo entrega datos puros (JSON), y es el navegador (el Cliente) quien asume la responsabilidad de dibujar y actualizar la interfaz gráfica.

Para lograr esto con alto rendimiento, la industria adoptó React, una librería basada en componentes desarrollada por Facebook.

### 1. El Problema del DOM y la Solución del Virtual DOM
El DOM (Document Object Model) es la representación en árbol que el navegador hace del HTML. Manipular el DOM real directamente (ej. con Vanilla JavaScript o jQuery) es una operación computacionalmente costosa y lenta.

React soluciona esto introduciendo el Virtual DOM: una copia ligera en la memoria RAM. Cuando los datos de nuestra aplicación cambian, React actualiza su Virtual DOM, compara la versión nueva con la versión anterior (un proceso algorítmico llamado Diffing), y calcula exactamente qué nodos cambiaron para ir a actualizar solo esos pequeños fragmentos en el DOM real.

### 2. Vite: El Estándar Moderno de Construcción
Históricamente usábamos Create React App (basado en Webpack) para iniciar proyectos. Sin embargo, en entornos ágiles modernos, el estándar es Vite. Vite es una herramienta de compilación de próxima generación que aprovecha los módulos nativos de ES (ECMAScript) en el navegador, ofreciendo un servidor de desarrollo que arranca en milisegundos y un Hot Module Replacement (HMR) casi instantáneo.

## 💻 Desarrollo Práctico: Inicialización del Ecosistema
Vamos a crear el proyecto Frontend que vivirá dentro de nuestro Monorepo, justo al lado de nuestra carpeta backend.

### Paso 1: Verificación del Entorno (Node.js)
Para trabajar con React y Vite, necesitamos que nuestro sistema operativo entienda el ecosistema de JavaScript. En la terminal, verifica que tienes instalado Node.js:

```bash
node -v
npm -v
```

### Paso 2: Scaffolding con Vite
Navega a la raíz de tu monorepo (fuera de la carpeta backend) y ejecuta el comando de creación de Vite. Le diremos que construya una plantilla configurada para React.

```bash
# Crea la carpeta 'frontend' utilizando la plantilla de React con JavaScript
npm create vite@latest frontend -- --template react

# Navegamos hacia la nueva carpeta
cd frontend

# Instalamos todas las dependencias del motor de React
npm install
```

### Paso 3: Análisis Arquitectónico del Proyecto
Abre la nueva carpeta frontend en tu editor de código. Como arquitectos, debemos entender cada pieza:

* **index.html**: Es el único archivo HTML de nuestra SPA. Contiene un `<div id="root"></div>`. Es un lienzo en blanco.

* **src/main.jsx**: Es el punto de entrada (Entry Point). Aquí React toma el control, localiza el div vacío del HTML y le "inyecta" toda nuestra aplicación.

* **src/App.jsx**: Es nuestro Componente Raíz. Todo lo que programemos nacerá desde este archivo.

### Paso 4: Levantando el Servidor de Desarrollo
Ejecutamos el comando para encender el servidor local de Vite:

```bash
npm run dev
```
La terminal nos indicará una ruta (generalmente http://localhost:5173). Si hacemos Ctrl + Clic en ella, el navegador se abrirá mostrando el logo de Vite y React girando.
